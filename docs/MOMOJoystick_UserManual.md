# 1. ภาพรวมผลิตภัณฑ์ (Overview)

## 1.1 ความเป็นมาและวัตถุประสงค์

**MOMO Joystick Controller** เป็นจอยบังคับไร้สายที่สื่อสารด้วยมาตรฐาน **Bluetooth Low Energy (BLE)** ออกแบบให้เชื่อมต่อกับบอร์ดไมโครคอนโทรลเลอร์ตระกูล **ESP32 และ ESP32-S3** ได้โดยตรง โดยไม่ต้องใช้โทรศัพท์มือถือ คอมพิวเตอร์ หรืออุปกรณ์รับสัญญาณ (ดองเกิล) เพิ่มเติม เหมาะสำหรับใช้เป็นอุปกรณ์ควบคุมหุ่นยนต์ในการเรียนการสอน การแข่งขัน และงานต้นแบบ

การใช้งานอาศัยไลบรารี **`Massmore_MomoJoy`** ซึ่งทำให้บอร์ด ESP32 ทำหน้าที่เป็น **BLE HID Host** คือเป็นฝ่ายค้นหา เชื่อมต่อ และรับข้อมูลจากจอยบังคับ ข้อมูลที่ได้ ได้แก่ ค่าก้านอนาล็อก ค่าไกอนาล็อก สถานะปุ่มกด และระดับแบตเตอรี่ ซึ่งอยู่ในรูปตัวเลขที่นำไปควบคุมมอเตอร์หรือเซอร์โวได้ทันที

คู่มือฉบับนี้มีวัตถุประสงค์เพื่อ

1. อธิบายหลักการทำงานและข้อมูลจำเพาะของจอยบังคับและไลบรารี
2. แนะนำขั้นตอนการติดตั้งเครื่องมือพัฒนาโดยละเอียด ตั้งแต่เริ่มต้นจนพร้อมใช้งาน
3. อธิบายการใช้งานร่วมกับบอร์ด **ESP32 Breakout (SKU-1015)** และ **MOMO ESP32-S3 (SKU-1020)** พร้อมโปรแกรมตัวอย่าง
4. รวบรวมแนวทางการแก้ไขปัญหาและแหล่งข้อมูลอ้างอิงสำหรับการศึกษาเพิ่มเติม

> **[ภาพที่ 1]** ภาพผลิตภัณฑ์ MOMO Joystick Controller มุมมองด้านหน้า
> พื้นที่สำหรับแทรกภาพ (ภาพแนะนำ: images/IMG_1395.jpeg)

> **[ภาพที่ 2]** แผนผังการทำงานของระบบ: จอยบังคับ → (สัญญาณ BLE) → บอร์ด ESP32 / ESP32-S3 → วงจรขับมอเตอร์ → มอเตอร์และเซอร์โวของหุ่นยนต์

## 1.2 คุณสมบัติเด่น (Features)

- **เชื่อมต่อกับ ESP32 ได้โดยตรง** บอร์ดทำหน้าที่เป็น BLE HID Host เอง ไม่ต้องใช้อุปกรณ์ตัวกลาง
- **ใช้มาตรฐาน Bluetooth Low Energy** ใช้พลังงานต่ำ จับคู่ครั้งเดียวแล้วบอร์ดจดจำไว้ เมื่อเปิดเครื่องครั้งถัดไปจะเชื่อมต่อให้อัตโนมัติ
- **ก้านอนาล็อก 2 ชุด** ให้ค่าละเอียดตั้งแต่ −512 ถึง 511 พร้อมระบบ Dead Zone แบบรัศมีที่ปรับค่าได้
- **ไกอนาล็อก L2 / R2** ให้ค่าตั้งแต่ 0 ถึง 1023 จึงใช้เป็นคันเร่งแบบปรับระดับได้
- **ปุ่มกดสูงสุด 18 ปุ่ม** และ **D-Pad** ที่แปลงเป็นทิศทางขึ้น ลง ซ้าย ขวา ให้พร้อมใช้งาน
- **อ่านระดับแบตเตอรี่ของจอยได้** ในช่วง 0–100% ผ่าน Battery Service มาตรฐาน
- **ระบุจอยด้วย MAC Address ได้** ป้องกันการเชื่อมต่อสลับเครื่อง เมื่อใช้งานจอยหลายตัวในห้องเดียวกัน
- **แปลความหมายข้อมูล HID ขณะทำงาน (Runtime HID Report Map Parsing)** จึงรองรับจอย BLE HID ทั่วไปได้ ไม่ผูกกับจอยรุ่นใดรุ่นหนึ่ง
- **มีไฟล์ติดตั้งพร้อมใช้** ในรูปแบบ `.zip` สำหรับ Arduino IDE และโปรเจกต์สำหรับ PlatformIO โดยรวมไลบรารี NimBLE-Arduino ไว้ในชุดแล้ว
- **โปรแกรมตัวอย่าง 6 ชุด** เรียงจากระดับพื้นฐานถึงระดับประยุกต์ ครอบคลุมทั้งบอร์ด ESP32 และ ESP32-S3

### 1.4.1 แกนอนาล็อก (Analog Axes)

| ส่วนควบคุม | คำสั่งที่ใช้อ่านค่า | ช่วงค่า | หมายเหตุ |
|---|---|---|---|
| ก้านซ้าย แกน X | `MomoJoy.lx()` | −512 ถึง 511 | 0 = ตำแหน่งกลาง, ค่าบวก = ด้านขวา |
| ก้านซ้าย แกน Y | `MomoJoy.ly()` | −512 ถึง 511 | **ดันขึ้นได้ค่าติดลบ** |
| ก้านขวา แกน X | `MomoJoy.rx()` | −512 ถึง 511 | 0 = ตำแหน่งกลาง, ค่าบวก = ด้านขวา |
| ก้านขวา แกน Y | `MomoJoy.ry()` | −512 ถึง 511 | ดันขึ้นได้ค่าติดลบ |
| ไกซ้าย L2 | `MomoJoy.l2()` | 0 ถึง 1023 | ค่าเพิ่มขึ้นตามระยะที่กด |
| ไกขวา R2 | `MomoJoy.r2()` | 0 ถึง 1023 | ค่าเพิ่มขึ้นตามระยะที่กด |

ทุกแกนมีคำสั่งรูปแบบทศนิยม (float) สำหรับการคำนวณ ได้แก่ `lxf()` `lyf()` `rxf()` `ryf()` ให้ค่า −1.0 ถึง 1.0 และ `l2f()` `r2f()` ให้ค่า 0.0 ถึง 1.0

> **หมายเหตุ** แกน Y ให้ค่าติดลบเมื่อดันก้านขึ้นตามมาตรฐาน HID หากต้องการใช้เป็นคำสั่งเดินหน้า ต้องกลับเครื่องหมายก่อน เช่น `int speed = -MomoJoy.ly();` หากไม่กลับเครื่องหมาย หุ่นยนต์จะเคลื่อนที่ถอยหลังเมื่อดันก้านไปข้างหน้า

## 1.5 ข้อปฏิบัติด้านความปลอดภัย

ผู้ใช้งานและผู้สอนควรปฏิบัติตามข้อกำหนดต่อไปนี้ทุกครั้งที่ทดลองกับหุ่นยนต์ที่มีมอเตอร์

1. ยกล้อหุ่นยนต์ให้พ้นพื้นทุกครั้งที่อัปโหลดโปรแกรมหรือทดสอบครั้งแรก
2. ตรวจสอบขั้วแบตเตอรี่และแรงดันไฟเลี้ยงให้อยู่ในช่วงที่บอร์ดกำหนดก่อนต่อวงจร
3. ปิดสวิตช์ไฟเลี้ยงก่อนต่อหรือถอดสายมอเตอร์ทุกครั้ง
4. ทดสอบปุ่มหยุดฉุกเฉิน (ปุ่ม **B** ในโปรแกรมตัวอย่าง) ก่อนวางหุ่นยนต์ลงพื้น
5. ไม่ปล่อยให้หุ่นยนต์ทำงานโดยไม่มีผู้ควบคุม และจัดพื้นที่ทดสอบให้ห่างจากขอบโต๊ะ

> **ข้อควรระวัง** โปรแกรมตัวอย่างทุกชุดกำหนดขาควบคุมมอเตอร์ให้เป็นสถานะ LOW เป็นคำสั่งแรกในฟังก์ชัน `setup()` ผ่านฟังก์ชัน `parkMotorPins()` เพื่อป้องกันมอเตอร์หมุนเองขณะบอร์ดเริ่มทำงาน เมื่อเขียนโปรแกรมใหม่สำหรับบอร์ดหุ่นยนต์ ผู้ใช้งานควรคงขั้นตอนนี้ไว้เสมอ

# 2. หลักการทำงานและข้อมูลจำเพาะ (Introduction & Specification)

## 2.1 หลักการทำงาน

จอยบังคับไร้สายทั่วไปมักใช้อุปกรณ์รับสัญญาณ 2.4 GHz เฉพาะรุ่น ซึ่งต้องเสียบเข้าพอร์ต USB และไม่สามารถใช้ร่วมกับบอร์ดไมโครคอนโทรลเลอร์ได้โดยตรง จอยบังคับรุ่นนี้ใช้มาตรฐาน **HID over GATT Profile (HOGP)** ซึ่งเป็นโปรไฟล์ของ Bluetooth Low Energy ที่กำหนดโดย Bluetooth SIG สำหรับอุปกรณ์รับคำสั่งจากผู้ใช้ เช่น แป้นพิมพ์ เมาส์ และจอยเกม เนื่องจาก ESP32 มีวงจร Bluetooth อยู่ภายในชิป ไลบรารีจึงทำให้บอร์ดเป็นฝ่ายเชื่อมต่อเข้าหาจอยได้โดยตรง

### ลำดับการทำงานเมื่อบอร์ดเริ่มทำงาน

```text
1. บอร์ดสแกนหาอุปกรณ์ที่ประกาศ HID Service (0x1812) หรือ Appearance = Gamepad (0x03C4)
2. พบจอย -> เชื่อมต่อและจับคู่ (Just Works + LE Secure Connections) แล้วบันทึกข้อมูลลงหน่วยความจำ NVS
3. ตั้งค่า Protocol Mode เป็น Report        (Characteristic 0x2A4E)
4. อ่าน Report Map แล้วแปลเป็นตารางข้อมูล   (Characteristic 0x2A4B)
5. ลงทะเบียนรับข้อมูลจาก Input Report       (Characteristic 0x2A4D, Descriptor 0x2908)
6. จอยส่งข้อมูลแบบ Notify -> คิวของ FreeRTOS -> ถอดรหัส -> ได้ค่าพร้อมใช้งาน
```

ขั้นตอนที่สำคัญคือการ **อ่าน Report Map** ซึ่งจอยจะระบุเองว่าข้อมูลแต่ละไบต์และแต่ละบิตหมายถึงแกนหรือปุ่มใด ไลบรารีจึงไม่ต้องกำหนดตำแหน่งข้อมูลไว้ตายตัว และสามารถใช้กับจอย BLE HID รุ่นอื่นได้ ส่วนที่อาจแตกต่างกันระหว่างรุ่นมีเพียงหมายเลขปุ่ม ซึ่งปรับได้ตามวิธีในหัวข้อ 8.4

> **หมายเหตุ** ต้องเลื่อนสวิตช์โหมดของจอยไปที่ตำแหน่ง **D** ทุกครั้งที่ใช้งานกับบอร์ด ESP32 เนื่องจากตำแหน่งนี้เป็นโหมด **BLE HID** ซึ่งเป็นโหมดเดียวที่ ESP32 สื่อสารด้วยได้ โหมดอื่นของจอยใช้ Bluetooth Classic หรือการสื่อสารเฉพาะ ซึ่ง ESP32-S3 ไม่รองรับ

3. หากโปรแกรมถามเรื่องการติดตั้งไดรเวอร์ USB ให้กด **Install** ทุกรายการ

**ระบบปฏิบัติการ macOS**

1. ดาวน์โหลดไฟล์ `.dmg` ให้ตรงกับชนิดของเครื่อง (**Apple Silicon** สำหรับชิป M1 ขึ้นไป หรือ **Intel**)
2. เปิดไฟล์ `.dmg` แล้วลากไอคอน Arduino IDE ไปวางในโฟลเดอร์ **Applications**
3. เปิดใช้งานครั้งแรก หากระบบแจ้งเตือนด้านความปลอดภัย ให้กด **Open**

**ระบบปฏิบัติการ Linux**

1. ดาวน์โหลดไฟล์ **AppImage 64 bits (X86-64)**
2. กำหนดสิทธิ์ให้เรียกใช้งานได้ด้วยคำสั่ง `chmod +x arduino-ide_*.AppImage`
3. เพิ่มสิทธิ์การใช้งานพอร์ตอนุกรมให้บัญชีผู้ใช้ แล้วออกจากระบบและเข้าสู่ระบบใหม่หนึ่งครั้ง

```bash
sudo usermod -a -G dialout $USER
```

> **หมายเหตุ** แนะนำให้ใช้ Arduino IDE เวอร์ชัน 2.x เนื่องจากรองรับ ESP32 Arduino Core 3.x ได้สมบูรณ์ และมีระบบจัดการบอร์ดและไลบรารีที่ใช้งานสะดวกกว่าเวอร์ชัน 1.8

### ขั้นตอนที่ 2 ติดตั้งไดรเวอร์ USB-to-Serial

คอมพิวเตอร์สื่อสารกับบอร์ดผ่านวงจรแปลง USB เป็น Serial ซึ่งแต่ละบอร์ดใช้ชิปต่างกัน ให้ติดตั้งไดรเวอร์ให้ตรงกับบอร์ดที่ใช้

| บอร์ด | ชิป USB-to-Serial | ชื่อพอร์ตที่ปรากฏโดยทั่วไป |
|---|---|---|
| MOMO ESP32-S3 (SKU-1020) | CH343P | Windows: `COMx` · macOS: `/dev/cu.usbmodemxxxx` หรือ `/dev/cu.wchusbserialxxxx` · Linux: `/dev/ttyACM0` |
| ESP32 Breakout (SKU-1015) | ตามรุ่นของโมดูล ESP32 (โดยทั่วไปเป็น CP2102 หรือ CH340) | Windows: `COMx` · macOS: `/dev/cu.usbserial-xxxx` หรือ `/dev/cu.SLAB_USBtoUART` · Linux: `/dev/ttyUSB0` |

**การติดตั้งไดรเวอร์ CH343P สำหรับบอร์ด MOMO ESP32-S3**

1. **Windows 10/11** โดยทั่วไประบบจะติดตั้งไดรเวอร์ให้อัตโนมัติผ่าน Windows Update หากไม่พบพอร์ต ให้ดาวน์โหลดไดรเวอร์ **CH343SER** จากเว็บไซต์ผู้ผลิต <https://www.wch-ic.com/products/CH343.html> แล้วติดตั้ง
2. **macOS 11 ขึ้นไป** ระบบรองรับชิปนี้ในตัว พอร์ตจะปรากฏเป็น `/dev/cu.usbmodemxxxx` หากต้องการใช้ไดรเวอร์ของผู้ผลิต ให้ดาวน์โหลดจากเว็บไซต์เดียวกัน แล้วอนุญาตส่วนขยายระบบที่ **System Settings → Privacy & Security**
3. **Linux** เคอร์เนลรองรับผ่านไดรเวอร์ `cdc_acm` ในตัว ไม่ต้องติดตั้งเพิ่ม

**การติดตั้งไดรเวอร์สำหรับบอร์ด ESP32 Breakout**

ตรวจสอบชื่อชิปที่พิมพ์อยู่บนโมดูล ESP32 แล้วติดตั้งไดรเวอร์ตามรุ่น ได้แก่ CP2102 จาก <https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers> หรือ CH340 จาก <https://www.wch-ic.com/downloads/CH341SER_EXE.html>

**การตรวจสอบว่าไดรเวอร์ทำงาน**

1. เสียบสาย USB ระหว่างคอมพิวเตอร์กับบอร์ด
2. Windows: เปิด **Device Manager** แล้วตรวจสอบหัวข้อ **Ports (COM & LPT)** ว่ามีพอร์ตใหม่ปรากฏขึ้น
3. macOS / Linux: เปิด Terminal แล้วพิมพ์คำสั่ง `ls /dev/cu.*` (macOS) หรือ `ls /dev/tty{USB,ACM}*` (Linux)

> **[ภาพที่ 5]** หน้าต่าง Device Manager แสดงพอร์ต COM ของชิป CH343P หลังติดตั้งไดรเวอร์สำเร็จ
> พื้นที่สำหรับแทรกภาพ

> **ข้อควรระวัง** สาย USB ต้องเป็นชนิดที่รับส่งข้อมูลได้ สายสำหรับชาร์จไฟเพียงอย่างเดียวจะทำให้คอมพิวเตอร์มองไม่เห็นบอร์ด แม้ไฟเลี้ยงบนบอร์ดจะติดตามปกติ

### ขั้นตอนที่ 7 ทดสอบการอัปโหลดโปรแกรม

ขั้นตอนนี้ใช้ตรวจสอบว่าคอมพิวเตอร์ บอร์ด และไลบรารีพร้อมทำงานร่วมกัน ก่อนเริ่มใช้งานจอยจริง

1. เลือกเมนู **File → New Sketch**
2. ลบโค้ดเดิมทั้งหมด แล้วพิมพ์โค้ดต่อไปนี้

```cpp
#include <Massmore_MomoJoy.h>
using namespace massmore;

void setup() {
  // กำหนดขาควบคุมมอเตอร์เป็น LOW ก่อน เพื่อป้องกันมอเตอร์หมุนเอง
#if CONFIG_IDF_TARGET_ESP32S3
  const uint8_t pins[] = {21, 38, 39, 40, 41, 42, 47, 48, 45};  // SKU-1020
#else
  const uint8_t pins[] = {27, 26, 16, 17, 19, 32, 33};          // SKU-1015
#endif
  for (uint8_t p : pins) { pinMode(p, OUTPUT); digitalWrite(p, LOW); }

  Serial.begin(115200);
  delay(500);
  Serial.println("Hello MOMO");
  Serial.printf("Chip    : %s\n", ESP.getChipModel());
  Serial.printf("Library : Massmore_MomoJoy v%s\n", MomoJoy.version());
}

void loop() {
}
```

3. กดปุ่ม **Verify** (เครื่องหมายถูก) เพื่อคอมไพล์ หากไม่มีข้อผิดพลาด ให้กดปุ่ม **Upload** (ลูกศรขวา)
4. เมื่ออัปโหลดเสร็จ เลือกเมนู **Tools → Serial Monitor** ตั้งค่าความเร็วที่มุมขวาเป็น **115200 baud** แล้วกดปุ่ม **RST** บนบอร์ดหนึ่งครั้ง

**ผลลัพธ์ที่ถูกต้อง**

```text
Hello MOMO
Chip    : ESP32-S3
Library : Massmore_MomoJoy v2.1.0
```

สำหรับบอร์ด ESP32 Breakout บรรทัด `Chip` จะแสดงชื่อรุ่นของชิป ESP32 เช่น `ESP32-D0WD-V3`

> **หมายเหตุ** หากอัปโหลดไม่สำเร็จและแจ้งข้อความ `Failed to connect` ให้กดปุ่ม **BOOT** ค้างไว้ กดปุ่ม **RST** หนึ่งครั้ง ปล่อยปุ่ม **RST** แล้วจึงปล่อยปุ่ม **BOOT** จากนั้นกด **Upload** อีกครั้ง

## 4.1 การจับคู่จอยครั้งแรก (ตัวอย่าง 01_Pairing)

### ขั้นตอนที่ 1 เปิดโปรแกรมตัวอย่าง

เลือกเมนู **File → Examples → Massmore_MomoJoy → 01_Pairing**

### ขั้นตอนที่ 2 อัปโหลดโปรแกรม

1. เสียบสาย USB ระหว่างคอมพิวเตอร์กับบอร์ด
2. ตรวจสอบการตั้งค่าในเมนู **Tools** ตามขั้นตอนที่ 6 ของบทที่ 3
3. กดปุ่ม **Upload**

### ขั้นตอนที่ 3 เปิด Serial Monitor

เลือกเมนู **Tools → Serial Monitor** และตั้งค่าความเร็วเป็น **115200 baud**

### ขั้นตอนที่ 4 เข้าสู่โหมดจับคู่ที่ตัวจอย

1. เลื่อน **สวิตช์โหมดไปที่ตำแหน่ง D**
2. กดปุ่ม **HOME ค้างไว้ประมาณ 3 วินาที** จนไฟแสดงสถานะ **กะพริบถี่** (หากไฟติดค้าง แสดงว่ายังไม่เข้าสู่โหมดจับคู่)
3. กดปุ่ม **RST** บนบอร์ดหนึ่งครั้ง บอร์ดจะค้นหาและเชื่อมต่อกับจอยเอง

> **[ภาพที่ 11]** ขั้นตอนเข้าสู่โหมดจับคู่: (ก) ตำแหน่งสวิตช์โหมด D (ข) ปุ่ม HOME และไฟแสดงสถานะที่กะพริบถี่
> พื้นที่สำหรับแทรกภาพ (ภาพ 2 ส่วนเรียงซ้าย-ขวา)

### ขั้นตอนที่ 5 ตรวจสอบผลใน Serial Monitor

เมื่อเชื่อมต่อสำเร็จ หน้าต่าง Serial Monitor จะแสดงข้อความในลักษณะต่อไปนี้

```text
Massmore MomoJoy - 01 Pairing
library v2.1.0
Put the joystick in pairing mode: switch to D, hold HOME 3 s.
=========================================
 CONNECTED
   name    : <ชื่อที่จอยประกาศ>
   address : xx:xx:xx:xx:xx:xx
   rssi    : -41 dBm
   battery : 87 %
=========================================
Press any button to confirm it works.
button: A
link: 66 Hz  rssi -42 dBm  battery 87%  packets 1520
```

เมื่อกดปุ่มบนจอย จะปรากฏบรรทัด `button:` ตามด้วยชื่อปุ่ม และทุก 1 วินาทีจะปรากฏบรรทัด `link:` แสดงอัตราการส่งข้อมูล ความแรงสัญญาณ ระดับแบตเตอรี่ และจำนวนแพ็กเก็ตที่ได้รับ

> **[ภาพที่ 12]** หน้าต่าง Serial Monitor แสดงผลการเชื่อมต่อสำเร็จจากตัวอย่าง 01_Pairing
> พื้นที่สำหรับแทรกภาพ

> **ข้อแนะนำ** ให้บันทึก MAC Address ของจอย (ค่าในบรรทัด `address`) ไว้ เพื่อใช้ในหัวข้อ 4.3 กรณีใช้งานจอยหลายตัว

### ขั้นตอนที่ 6 การเชื่อมต่อในครั้งถัดไป

ข้อมูลการจับคู่ถูกบันทึกในหน่วยความจำ NVS ของบอร์ด เมื่อเปิดบอร์ดและจอยในครั้งถัดไป ระบบจะเชื่อมต่อให้อัตโนมัติโดยไม่ต้องจับคู่ใหม่

หากต้องการล้างข้อมูลการจับคู่ เช่น เพื่อเปลี่ยนไปใช้จอยตัวอื่น ให้ **กดปุ่ม SELECT และ START ค้างพร้อมกันประมาณ 1.5 วินาที** ขณะที่จอยยังเชื่อมต่ออยู่ แล้วจับคู่ใหม่ตามขั้นตอนที่ 4

## 4.2 การอ่านค่าทั้งหมดจากจอย (ตัวอย่าง 02_ReadAllSerial)

โปรแกรมตัวอย่างนี้แสดงค่าของก้าน ไก D-Pad ปุ่ม และระดับแบตเตอรี่ทางหน้าต่าง Serial Monitor โดยแสดงเฉพาะเมื่อค่ามีการเปลี่ยนแปลง จึงอ่านผลได้ง่าย เหมาะสำหรับการเรียนรู้ความหมายของค่าแต่ละแกน และใช้เป็นเครื่องมือปรับเทียบปุ่ม

### ขั้นตอนการใช้งาน

1. เลือกเมนู **File → Examples → Massmore_MomoJoy → 02_ReadAllSerial**
2. เลือกรูปแบบการแสดงผลที่บรรทัดด้านบนของโปรแกรม แล้วอัปโหลด
3. เปิด Serial Monitor ที่ความเร็ว **115200 baud** แล้วทดลองกดปุ่มและโยกก้านทีละรายการ

```cpp
#define SHOW_RAW_REPORTS 0     // 1 = แสดงข้อมูลดิบของ HID สำหรับการปรับเทียบ
#define OUTPUT_FORMAT    0     // 0 = ข้อความ, 1 = CSV, 2 = JSON
```

| ค่า `OUTPUT_FORMAT` | รูปแบบ | การนำไปใช้ |
|---|---|---|
| 0 | ข้อความสำหรับอ่าน | การเรียนรู้และตรวจสอบค่าด้วยสายตา |
| 1 | CSV ลำดับคอลัมน์ `lx,ly,rx,ry,l2,r2,dpad,buttons,battery` | บันทึกข้อมูลเพื่อนำไปวิเคราะห์หรือเขียนกราฟ |
| 2 | JSON หนึ่งบรรทัดต่อหนึ่งชุดข้อมูล | ส่งต่อให้โปรแกรมบนคอมพิวเตอร์หรือเว็บไซต์ |

> **ข้อแนะนำ** ในการเรียนการสอน สามารถใช้รูปแบบ CSV ร่วมกับเครื่องมือ **Tools → Serial Plotter** ของ Arduino IDE เพื่อแสดงกราฟค่าก้านแบบเวลาจริงได้

## 4.3 การใช้งานจอยหลายตัวในพื้นที่เดียวกัน (ตัวอย่าง 03_PairByAddress)

โดยค่าเริ่มต้น ไลบรารีจะเชื่อมต่อกับ **จอยตัวแรกที่ตรวจพบ** หากเปิดจอยหลายตัวพร้อมกัน เช่น ในห้องเรียนหรือสายการผลิต บอร์ดอาจเชื่อมต่อกับจอยผิดตัว วิธีแก้ไขคือการระบุจอยด้วย **MAC Address** โดยดำเนินการ 2 รอบ

### ขั้นตอนที่ 1 ค้นหา MAC Address ของจอย

1. เลือกเมนู **File → Examples → Massmore_MomoJoy → 03_PairByAddress**
2. คงค่าบรรทัดต่อไปนี้ไว้เป็นค่าว่างตามเดิม แล้วอัปโหลด

```cpp
#define TARGET_ADDRESS ""
```

3. เปิด Serial Monitor บอร์ดจะสแกนประมาณ 6 วินาที แล้วแสดงรายชื่อจอยทุกตัวในระยะ

```text
=========================================
 2 gamepad(s) in range
 #  rssi   address             name
 -----------------------------------------
 1   -41   aa:bb:cc:dd:ee:01   <ชื่อจอยตัวที่ 1>
 2   -73   aa:bb:cc:dd:ee:02   <ชื่อจอยตัวที่ 2>
=========================================
```

คอลัมน์ **rssi** แสดงความแรงสัญญาณ ค่าที่ใกล้ 0 หมายถึงจอยอยู่ใกล้บอร์ดมากกว่า ใช้ประกอบการระบุว่าจอยตัวใดเป็นของผู้ใช้งาน

### ขั้นตอนที่ 2 กำหนด MAC Address แล้วอัปโหลดใหม่

```cpp
#define TARGET_ADDRESS "aa:bb:cc:dd:ee:01"
```

หลังอัปโหลด บอร์ดจะเชื่อมต่อกับจอยตัวที่กำหนดเพียงตัวเดียว และเชื่อมต่อให้เองทุกครั้งที่เปิดเครื่องโดยไม่ต้องกดปุ่มใด

### ทางเลือกสำหรับโต๊ะปฏิบัติการที่มีจอยเพียงตัวเดียว

กำหนดค่าต่อไปนี้เป็น `1` บอร์ดจะเลือกจอยที่มีสัญญาณแรงที่สุดให้อัตโนมัติ

```cpp
#define AUTO_PICK_STRONGEST 1
```

### การนำไปใช้ในโปรแกรมของผู้ใช้งาน

```cpp
MomoJoyOptions opt;
opt.addressFilter = "aa:bb:cc:dd:ee:01";   // เชื่อมต่อกับจอยตัวนี้เท่านั้น
// opt.nameFilter = "MOMO";                // หรือกรองด้วยชื่อที่จอยประกาศ
MomoJoy.begin(opt);
```

| คำสั่ง | หน้าที่ |
|---|---|
| `opt.autoStart = false` | ให้ `begin()` เตรียมระบบ BLE โดยยังไม่เชื่อมต่อกับจอยตัวแรกที่พบ |
| `scanDevices(ms)` | สแกนโดยไม่เชื่อมต่อ คืนค่าจำนวนจอยที่พบ (สูงสุด 8 ตัว) |
| `foundDevice(i)` | อ่านข้อมูล `.name` `.address` `.rssi` ของจอยลำดับที่ i |
| `setAddressFilter(mac)` | เปลี่ยน MAC Address ที่ต้องการขณะโปรแกรมทำงาน |
| `connectToAddress(mac)` | กำหนด MAC Address และเริ่มค้นหาในคำสั่งเดียว |

> **ข้อแนะนำ** สำหรับห้องปฏิบัติการ แนะนำให้ติดป้ายหมายเลขที่จอยและบอร์ดให้ตรงกัน พร้อมบันทึก MAC Address ของแต่ละคู่ไว้ในใบบันทึกประจำโต๊ะ เพื่อความสะดวกในการจัดการเมื่อใช้งานจำนวนมาก

# 5. การใช้งานกับบอร์ด ESP32 Breakout (SKU-1015)

## 5.1 ข้อมูลบอร์ด

บอร์ด ESP32 Breakout เป็นบอร์ดขยายสำหรับโมดูล **ESP32 38PIN** มีวงจรแปลงแรงดันไฟ จุดต่อสัญญาณควบคุมมอเตอร์ 2 ช่อง ช่องเซอร์โว 3 ช่อง ตัวต้านทานปรับค่า (VR) และสวิตช์บนบอร์ด เหมาะสำหรับหุ่นยนต์ขับเคลื่อน 2 ล้อ

> **[ภาพที่ 13]** บอร์ด ESP32 Breakout (SKU-1015) ระบุตำแหน่งขั้วไฟเลี้ยง ช่องโมดูลขับมอเตอร์ ช่องมอเตอร์ M1/M2 ช่องเซอร์โว VR และ SW
> พื้นที่สำหรับแทรกภาพ

### 5.1.1 ผังขาที่โปรแกรมตัวอย่างใช้งาน

| หน้าที่ | สัญญาณ | GPIO | หมายเหตุ |
|---|---|---|---|
| มอเตอร์ซ้าย M1 | IN1 / IN2 | **27 / 26** | ส่งสัญญาณไปยังโมดูลขับมอเตอร์ภายนอก |
| มอเตอร์ขวา M2 | IN1 / IN2 | **16 / 17** | ส่งสัญญาณไปยังโมดูลขับมอเตอร์ภายนอก |
| เซอร์โว 1 / 2 / 3 | Servo | **19 / 32 / 33** | สัญญาณ PWM 50 Hz |
| ตัวต้านทานปรับค่า | VR | **34** | อินพุตอนาล็อก ใช้ตั้งความเร็วสูงสุด |
| สวิตช์บนบอร์ด | SW | **36** | ขาอินพุตเท่านั้น |
| บัส I2C | SDA / SCL | 21 / 22 | สำหรับจอ OLED และเซนเซอร์ |
| จอแสดงผล SPI | CLK / MOSI / RES / DC | 18 / 23 / 4 / 2 | ไม่ได้ใช้ในตัวอย่าง |
| ขาอเนกประสงค์ | IO1–IO7 | 25 / 13 / 12 / 14 / 15 / 5 / 35 | สำรองสำหรับต่อขยาย |

> **ข้อควรระวัง** บอร์ด SKU-1015 **ไม่มีวงจรขับมอเตอร์บนบอร์ด** ขา IN1 / IN2 เป็นสัญญาณควบคุมที่ส่งไปยังโมดูลขับมอเตอร์ภายนอก (TB6612FNG หรือเทียบเท่า) ต้องติดตั้งโมดูลขับมอเตอร์ก่อน จึงจะขับมอเตอร์ได้ ห้ามต่อมอเตอร์เข้ากับขา GPIO โดยตรง

## 5.2 อุปกรณ์ที่ต้องใช้

| ลำดับ | อุปกรณ์ | จำนวน |
|---|---|---|
| 1 | MOMO Joystick Controller (SKU-1001) | 1 ตัว |
| 2 | บอร์ด ESP32 Breakout (SKU-1015) พร้อมโมดูล ESP32 38PIN | 1 ชุด |
| 3 | โมดูลขับมอเตอร์ TB6612FNG หรือเทียบเท่า | 1 โมดูล |
| 4 | มอเตอร์เกียร์ DC พร้อมล้อ | 2 ชุด |
| 5 | แบตเตอรี่แรงดัน 6–12 V | 1 ก้อน |
| 6 | เซอร์โวมอเตอร์ (ถ้าต้องการทดลองปุ่ม A) | 1 ตัว |
| 7 | สาย USB ชนิดรับส่งข้อมูลได้ | 1 เส้น |

## 5.3 การต่อวงจร

> **[ภาพที่ 14]** แผนผังการต่อวงจรหุ่นยนต์ 2 ล้อ: แบตเตอรี่ → บอร์ด SKU-1015 → โมดูลขับมอเตอร์ → มอเตอร์ซ้าย (M1) และมอเตอร์ขวา (M2)
> พื้นที่สำหรับแทรกภาพ

1. ปิดสวิตช์ไฟเลี้ยงทั้งหมดก่อนเริ่มต่อวงจร
2. ติดตั้งโมดูล ESP32 38PIN และโมดูลขับมอเตอร์ลงบนบอร์ดให้ถูกทิศทาง
3. ต่อมอเตอร์ล้อซ้ายเข้าช่อง **M1** และมอเตอร์ล้อขวาเข้าช่อง **M2**
4. ต่อเซอร์โวเข้าช่อง **Servo1** (ถ้ามี) โดยตรวจสอบตำแหน่งสายสัญญาณ ไฟเลี้ยง และกราวด์
5. ต่อแบตเตอรี่แรงดัน **6–12 V** เข้าขั้ว VIN ของบอร์ด โดยตรวจสอบขั้วบวกและลบให้ถูกต้อง
6. ยกล้อหุ่นยนต์ให้พ้นพื้นก่อนทดสอบครั้งแรก

## 5.4 การอัปโหลดโปรแกรมตัวอย่าง 04_Robot2WD_ESP32

1. เลือกเมนู **File → Examples → Massmore_MomoJoy → 04_Robot2WD_ESP32**
2. ตั้งค่าเมนู **Tools** ตามตารางในบทที่ 3 ขั้นตอนที่ 6.2 โดยเฉพาะ **Partition Scheme = Huge APP**
3. กดปุ่ม **Upload** แล้วเปิด Serial Monitor ที่ความเร็ว **115200 baud**
4. หากยังไม่เคยจับคู่จอยกับบอร์ดนี้ ให้ทำตามหัวข้อ 4.1 ขั้นตอนที่ 4

## 5.5 วิธีการบังคับ

| ปุ่ม / แกน | การทำงาน |
|---|---|
| **ก้านซ้าย** | ควบคุมการเคลื่อนที่ทั้งหมดด้วยก้านเดียว ดันขึ้น/ลง = เดินหน้า/ถอยหลัง ดันซ้าย/ขวา = เลี้ยว ความเร็วแปรผันตามระยะที่ดัน |
| **D-Pad** | เคลื่อนที่ตามทิศของปุ่มด้วยความเร็วคงที่ |
| **R2** | เพิ่มความเร็วจากค่าที่ก้านกำหนด ตามระยะที่กดไก |
| **Y (กดค้าง)** | โหมดความเร็วสูง (Turbo) |
| **A** | ปรับมุมเซอร์โว 1 ตามลำดับ 0° → 90° → 180° |
| **L1 / R1 (กดค้าง)** | ทดสอบหมุนล้อซ้าย / ล้อขวาทีละข้าง |
| **B** | หยุดฉุกเฉิน |
| **HOME (กดค้าง 2 วินาที)** | ล้างข้อมูลการจับคู่ BLE |
| **VR บนบอร์ด** | กำหนดความเร็วสูงสุดในช่วง 70–200 (จาก 255) ปรับได้ทันทีโดยไม่ต้องแก้ไขโปรแกรม |

## 5.6 การปรับค่าการตอบสนอง

ค่าต่อไปนี้อยู่ในส่วน `#define` ด้านบนของโปรแกรมตัวอย่าง

| ชื่อค่า | ค่าเริ่มต้น | ความหมายและแนวทางการปรับ |
|---|---|---|
| `SPEED_MIN` / `SPEED_MAX` | 70 / 200 | ช่วงความเร็วสูงสุดที่ปรับด้วย VR |
| `SPEED_TURBO` | 255 | ความเร็วขณะกดปุ่ม Y ค้าง |
| `SPEED_DPAD` | 110 | ความเร็วคงที่เมื่อใช้ D-Pad |
| `SPEED_TEST` | 150 | ความเร็วขณะทดสอบล้อด้วย L1 / R1 |
| `MOTOR_MIN_DUTY` | 40 | ค่าต่ำสุดที่มอเตอร์เริ่มหมุน หากหุ่นยนต์สั่นแต่ไม่เคลื่อนที่ ให้เพิ่มเป็น 50–60 |
| `EXPO_AMOUNT` | 0.60 | ความนุ่มนวลช่วงกลางก้าน ค่ามากขึ้นจะควบคุมความเร็วต่ำได้ละเอียดขึ้น |
| `TURN_GAIN` | 0.65 | ความไวในการเลี้ยว |
| `SLEW_UP` / `SLEW_DOWN` | 6 / 24 | อัตราการเร่งและการลดความเร็วต่อรอบควบคุม (รอบละ 20 มิลลิวินาที) |

## 5.7 โครงสร้างโปรแกรมส่วนสำคัญ

```cpp
void setup() {
  parkMotorPins();          // 1) กำหนดขามอเตอร์เป็น LOW เป็นคำสั่งแรก
  Serial.begin(115200);
  motorsBegin();            //    ตั้งค่า PWM 20 kHz ให้ขามอเตอร์

  MomoJoyOptions opt;
  opt.deadzone = 40;        //    งานหุ่นยนต์ใช้ Dead Zone กว้างกว่างานเกม
  MomoJoy.begin(opt);
}

void loop() {
  MomoJoy.update();
  // 2) ระบบความปลอดภัย: ไม่มีสัญญาณ หรือไม่ได้รับข้อมูลเกิน 400 ms ให้หยุดทันที
  if (!MomoJoy.isConnected() || MomoJoy.msSinceReport() > 400) {
    motorsStop();
    return;
  }
  // 3) ก้านซ้าย: แกน Y = เดินหน้า/ถอยหลัง, แกน X = เลี้ยว
  int maxSpeed = MomoJoy.pressed(MOMO_BTN_Y) ? SPEED_TURBO : knobSpeed();
  // ... คำนวณความเร็วล้อซ้าย/ขวา แล้วสั่งงานมอเตอร์
}
```

โค้ดข้างต้นเป็นโครงสร้างโดยย่อเพื่อการอธิบาย รายละเอียดฉบับเต็มอยู่ในไฟล์ `04_Robot2WD_ESP32.ino`

# 6. การใช้งานกับบอร์ด MOMO ESP32-S3 (SKU-1020)

## 6.1 ข้อมูลบอร์ด

บอร์ด MOMO ESP32-S3 เป็นบอร์ดพัฒนาหุ่นยนต์ที่มี **วงจรขับมอเตอร์ TB67H451AFNG จำนวน 4 ช่อง** บนบอร์ด รองรับ Encoder ของมอเตอร์ทั้ง 4 ตัว มี Buzzer และช่องต่อจอแสดงผล เหมาะสำหรับหุ่นยนต์ 4 ล้อ รวมถึงหุ่นยนต์ล้อ Mecanum ที่เคลื่อนที่ได้รอบทิศทาง

> **[ภาพที่ 15]** บอร์ด MOMO ESP32-S3 (SKU-1020) ระบุตำแหน่งขั้วไฟเลี้ยง (Terminal / XT30) สวิตช์ Power ช่องมอเตอร์ M1–M4 IO Header ปุ่ม BOOT/RST และพอร์ต USB
> พื้นที่สำหรับแทรกภาพ

### 6.1.1 ผังขาที่โปรแกรมตัวอย่างใช้งาน

| มอเตอร์ | IN1 | IN2 | Encoder A / B | ตำแหน่งล้อในโปรแกรมตัวอย่าง |
|---|---|---|---|---|
| M1 | **GPIO 21** | **GPIO 38** | GPIO 1 / 2 | หลังขวา (Rear-Right) |
| M2 | **GPIO 39** | **GPIO 40** | GPIO 16 / 17 | หน้าขวา (Front-Right) |
| M3 | **GPIO 41** | **GPIO 42** | GPIO 7 / 8 | หน้าซ้าย (Front-Left) |
| M4 | **GPIO 47** | **GPIO 48** | GPIO 9 / 10 | หลังซ้าย (Rear-Left) |
| Buzzer | **GPIO 45** | — | — | Buzzer บนบอร์ด |

### 6.1.2 การเทียบชื่อขาบน IO Header สำหรับสาย Encoder

| ชื่อบนบอร์ด | GPIO | ใช้งานเป็น |
|---|---|---|
| IO1 / IO2 | 1 / 2 | Encoder M1 A / B |
| IO10 / IO11 | 16 / 17 | Encoder M2 A / B |
| IO6 / IO7 | 7 / 8 | Encoder M3 A / B |
| IO8 / IO9 | 9 / 10 | Encoder M4 A / B |

> **ข้อควรระวัง** ขา **IO11 (GPIO 17)** ใช้ร่วมกับสัญญาณ TFT_CS ของจอแสดงผล หากโครงงานต้องใช้จอแสดงผลด้วย ห้ามใช้ IO11 เป็นสาย Encoder พร้อมกัน ให้ย้าย Encoder ของ M2 ไปใช้ขาอื่น แล้วแก้ไขหมายเลขขาในโปรแกรม

## 6.3 การต่อวงจร

> **[ภาพที่ 16]** แผนผังการต่อวงจรหุ่นยนต์ 4 ล้อ: แบตเตอรี่ (XT30) → บอร์ด, มอเตอร์ M1–M4 ตามตำแหน่งล้อ, สาย Encoder → IO Header และทิศทางการวางล้อ Mecanum เมื่อมองจากด้านบน
> พื้นที่สำหรับแทรกภาพ

1. ปิดสวิตช์ Power บนบอร์ดก่อนเริ่มต่อวงจร
2. ต่อมอเตอร์ 4 ตัวเข้าช่อง **M1–M4** ตามตำแหน่งล้อในตารางหัวข้อ 6.1.1
3. ต่อสาย Encoder เข้า **IO Header** ตามตารางหัวข้อ 6.1.2
4. ต่อแบตเตอรี่แรงดัน **6–16 V** เข้าขั้ว **Terminal Block** หรือ **XT30** โดยตรวจสอบขั้วให้ถูกต้อง
5. **เปิดสวิตช์ Power บนบอร์ด** และยกล้อหุ่นยนต์ให้พ้นพื้นก่อนทดสอบครั้งแรก

> **ข้อควรระวัง** ต้องเปิดสวิตช์ Power บนบอร์ดทุกครั้งที่ต้องการขับมอเตอร์ หากปิดสวิตช์ไว้ บอร์ดจะได้รับไฟจากพอร์ต USB เพียงอย่างเดียว ซึ่งโปรแกรมทำงานได้แต่ไม่เพียงพอสำหรับขับมอเตอร์ อาการที่พบคือมอเตอร์ไม่หมุนแม้ต่อวงจรถูกต้องทั้งหมด

## 6.6 การกำหนดชนิดล้อ

โปรแกรมตัวอย่างกำหนดค่าเริ่มต้นเป็น **ล้อ Mecanum** หากหุ่นยนต์ใช้ล้อปกติ ให้แก้ไขค่าต่อไปนี้เป็น `0` ก้านซ้ายจะควบคุมเฉพาะการเดินหน้าและถอยหลัง

```cpp
#define MECANUM_WHEELS   0     // 1 = ล้อ Mecanum, 0 = ล้อปกติ
```

สมการผสมกำลังล้อ Mecanum ที่โปรแกรมตัวอย่างใช้ เป็นสมการมาตรฐานดังนี้

```text
ล้อหน้าซ้าย  (FL) = fwd + strafe + rot
ล้อหน้าขวา  (FR) = fwd - strafe - rot
ล้อหลังซ้าย (RL) = fwd - strafe + rot
ล้อหลังขวา  (RR) = fwd + strafe - rot
```

โดย `fwd` คือค่าเดินหน้า `strafe` คือค่าเคลื่อนที่ด้านข้าง และ `rot` คือค่าหมุนตัว เมื่อคำนวณแล้วมีล้อใดเกินค่าสูงสุด โปรแกรมจะลดสเกลของทั้ง 4 ล้อในอัตราส่วนเดียวกัน เพื่อรักษาทิศทางการเคลื่อนที่ไม่ให้เบี่ยงเบน

> **ข้อแนะนำ** หากล้อใดหมุนกลับทิศ ให้สลับสายมอเตอร์ 2 เส้นของล้อนั้น หรือสลับหมายเลขขา IN1 / IN2 ของล้อนั้นในโปรแกรม โดยไม่ต้องแก้ไขสมการ


บรรทัดที่ขึ้นต้นด้วย `#TEST` `#RESULT` และ `#VERDICT` ออกแบบให้โปรแกรมบนคอมพิวเตอร์อ่านไปประมวลผลต่อได้ ส่วนบรรทัดอื่นเป็นข้อความสำหรับผู้ทดสอบ ผลการทดสอบสามารถบันทึกลงแบบฟอร์มในภาคผนวก ข

> **หมายเหตุ** ปุ่ม HOME ไม่อยู่ในรายการทดสอบ เนื่องจากจอยใช้ปุ่มนี้สำหรับเปิด-ปิดเครื่องและเข้าสู่โหมดจับคู่ ซึ่งจอยจัดการภายในโดยไม่ส่งค่าออกมา หากต้องการทดสอบปุ่มนี้กับจอยที่ส่งค่าได้ ให้กำหนด `#define TEST_HOME_BUTTON 1`

## 7.4 เฟิร์มแวร์สำเร็จรูป

โฟลเดอร์ `firmware` ในคลังข้อมูล GitHub มีไฟล์เฟิร์มแวร์ที่คอมไพล์ไว้แล้วสำหรับบอร์ด ESP32-S3 สามารถติดตั้งได้โดยไม่ต้องคอมไพล์

| ไฟล์ | ตำแหน่งเขียน (Offset) | รายละเอียด |
|---|---|---|
| **`MomoJoy_FactoryTest_esp32s3_merged.bin`** | **`0x0`** | ไฟล์รวม (Bootloader + Partition Table + boot_app0 + โปรแกรม) **ใช้ไฟล์นี้กับเว็บไซต์สำหรับติดตั้งเฟิร์มแวร์** |
| `MomoJoy_FactoryTest_esp32s3.bin` | `0x10000` | เฉพาะส่วนโปรแกรม |
| `bootloader_esp32s3.bin` | `0x0` | Bootloader |
| `partitions_esp32s3.bin` | `0x8000` | Partition Table |

การติดตั้งด้วยโปรแกรม esptool

```bash
pip install -U esptool
esptool.py --chip esp32s3 --port <ชื่อพอร์ต> --baud 921600 \
           write_flash -z 0x0 MomoJoy_FactoryTest_esp32s3_merged.bin
```

> **ข้อควรระวัง** ห้ามติดตั้งไฟล์ส่วนโปรแกรมเพียงไฟล์เดียวที่ตำแหน่ง `0x0` เนื่องจากไม่มี Bootloader บอร์ดจะไม่สามารถเริ่มทำงานได้ ให้ใช้ไฟล์ที่ลงท้ายด้วย `_merged.bin` เท่านั้น

## 8.4 การปรับเทียบปุ่มสำหรับจอยรุ่นอื่น

หากนำไลบรารีไปใช้กับจอย BLE HID รุ่นอื่น แล้วชื่อปุ่มที่แสดงไม่ตรงกับปุ่มที่กด ให้ดำเนินการดังนี้

1. เปิดตัวอย่าง `02_ReadAllSerial` แล้วกำหนด `#define SHOW_RAW_REPORTS 1`
2. อัปโหลดแล้วเปิด Serial Monitor จะปรากฏตาราง HID Report Map และข้อมูลดิบของทุก Report
3. กดปุ่มทีละปุ่ม สังเกตบิตที่เปลี่ยนแปลง แล้วบันทึกหมายเลขปุ่ม HID
4. สร้างตารางปุ่มของผู้ใช้งาน แล้วกำหนดให้กับ `opt.profile`

```cpp
static const MomoButtonMap kMyMap[] = {
    {1, MOMO_BTN_A}, {2, MOMO_BTN_B}, {4, MOMO_BTN_X}, {5, MOMO_BTN_Y},
    // ... เพิ่มหมายเลขปุ่มตามที่ตัวอย่าง 02 แสดง
};
static const MomoProfile kMyProfile = {"my pad", kMyMap,
    (uint8_t)(sizeof(kMyMap) / sizeof(kMyMap[0])), false, false};

MomoJoyOptions opt;
opt.profile = &kMyProfile;
MomoJoy.begin(opt);
```

# 9. ข้อแนะนำสำหรับการใช้งาน (Pro Tips)

1. **ระบบหยุดฉุกเฉินต้องมีเสมอ** ในหุ่นยนต์ที่มีล้อ ไม่ควรตรวจสอบเพียง `isConnected()` แต่ควรตรวจสอบ `msSinceReport() > 400` ร่วมด้วย เนื่องจากอาจมีกรณีที่สถานะยังเชื่อมต่อแต่จอยหยุดส่งข้อมูลแล้ว
2. **ปรับ Dead Zone ให้เหมาะกับงาน** งานเกมใช้ค่าประมาณ 16–24 ส่วนงานหุ่นยนต์ควรใช้ 40–48 เพื่อป้องกันหุ่นยนต์เคลื่อนที่เองเมื่อปล่อยก้าน
3. **ใช้ไกอนาล็อกเป็นคันเร่ง** คำสั่ง `l2f()` / `r2f()` ให้ค่า 0.0–1.0 นำไปคูณกับความเร็วสูงสุดได้โดยตรง ให้การควบคุมที่นุ่มนวลกว่าการใช้ปุ่มกด
4. **ตรวจสอบคุณภาพสัญญาณก่อนใช้งานจริง** ค่า `reportRateHz()` ปกติอยู่ที่ประมาณ 60–125 Hz หากต่ำกว่า 30 Hz แสดงว่าสัญญาณถูกรบกวนหรือระยะไกลเกินไป
5. **แจ้งเตือนแบตเตอรี่ต่ำ** ใช้ค่า `battery()` ร่วมกับ Buzzer หรือจอแสดงผล เพื่อแจ้งเตือนเมื่อแบตเตอรี่ของจอยต่ำกว่า 20%
6. **ระบุจอยด้วย MAC Address ในงานที่ต้องการความแน่นอน** เช่น ห้องเรียนและสายการผลิต เพื่อป้องกันการเชื่อมต่อสลับเครื่อง
7. **จัดเตรียมบอร์ดสำหรับตรวจสอบจอย** ติดตั้งเฟิร์มแวร์ Factory Test ไว้บนบอร์ดสำรองหนึ่งบอร์ด เพื่อใช้ตรวจสอบจอยแต่ละตัวได้ภายในเวลาไม่เกิน 2 นาที

# ภาคผนวก ก สรุปคำสั่งของไลบรารี

```cpp
#include <Massmore_MomoJoy.h>
using namespace massmore;

void setup() {
  Serial.begin(115200);
  MomoJoy.begin();                 // ค้นหา จับคู่ และเชื่อมต่ออัตโนมัติ
}

void loop() {
  MomoJoy.update();                // ต้องเรียกทุกรอบของ loop()
  if (!MomoJoy.isConnected()) return;

  if (MomoJoy.justPressed(MOMO_BTN_A)) Serial.println("A");

  int speed = -MomoJoy.ly();       // -512..511 (ดันขึ้นได้ค่าติดลบ จึงกลับเครื่องหมาย)
  int brake =  MomoJoy.l2();       //    0..1023
}
```
